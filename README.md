# Clone FreeCodeCamp DevWeb 🎓

Collection de projets web frontend créée en suivant des exercices et tutoriels FreeCodeCamp. Chaque projet montre des compétences en HTML, CSS et JavaScript Vanilla, avec des interfaces interactives et des démonstrations de concepts web.

## 📂 Projets Inclus

1. **[Color Palette Generator](./Color-palette-generator/)** - Générateur de palettes de couleurs
2. **[Drag And Drop](./Drag-And-Drop/)** - Tableau Kanban avec drag & drop
3. **[Quiz Game](./QUIZ-GAME/)** - Jeu de quiz interactif
4. **[Expense Tracker](./expense_tracker/)** - Suivi des dépenses et revenus
5. **[Emoji Reactor](./emojiReactor/)** - Sélecteur d'émojis d'humeur
6. **[Penguin CSS Art](./penguin/)** - Illustration CSS d'un pingouin
7. **[Rock Paper Scissors](./RockPaperScissors/)** - Jeu Pierre-Papier-Ciseaux
8. **[RegExp Demo](./RegExp/)** - Exemples d'expressions régulières
9. **[Football Team](./footballTeam/)** - Playlist d'équipe et cartes de joueurs
10. **[DOM Examples](./dom/)** - Démonstrations de manipulation DOM et formulaires

## 🛠️ Technologies Utilisées

- **CSS3** - Mise en page, responsivité et animations

## 📦 Comment Utiliser

### Prérequis
- Un navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Aucune installation requise

### Exécution
Chaque projet est autonome. Pour exécuter un projet :

1. Naviguez vers le dossier du projet.
2. Ouvrez le fichier `index.html` dans votre navigateur.
   - Double-cliquez sur `index.html`, ou
   - Clic droit → "Open with" → Choisissez votre navigateur

### Avec un serveur local (recommandé)

Si vous avez Python 3 installé :
```bash
python -m http.server 8000
```
Puis ouvrez `http://localhost:8000` dans votre navigateur.

Ou avec Node.js si vous avez `http-server` :
```bash
npx http-server
```
